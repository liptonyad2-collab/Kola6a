# Kola6a CRM

CRM для домиков, пляжа, развлечений и водного транспорта, дополнительных услуг и аренды территории.

## Состояние

**Этап 2:** база Supabase содержит 5 направлений, 11 категорий и 28 черновых услуг. Добавлен вход по email/паролю и защищённый просмотр каталога. Для входа нужен пользователь Supabase Auth с назначенной ролью в `public.profiles`.

Пока **нет** интерфейса редактирования, продаж, онлайн-оплаты и бронирований. Не используйте текущий прототип как готовую финансовую систему.

## Запуск

Node.js 20+:

```bash
npm install
cp .env.example .env.local
# В .env.local укажите только publishable Supabase key
npm run dev
```

Откройте http://localhost:3000/login.

## Настройка

- [Настройка учётной записи владельца](docs/AUTH_SETUP.md)
- [План разработки](docs/ROADMAP.md)
- SQL-схема: `supabase/migrations/0001_initial.sql`
- Каталог и RLS: `supabase/migrations/0002_catalog_and_read_policies.sql` (уже применено к подключённому проекту; файл для будущих баз, **не запускать повторно**)

Защита: RLS запрещает доступ к продажам и финансам; каталог доступен только авторизованным участникам с ролью. Секретные ключи нельзя хранить в репозитории. В production необходимо тестирование сборки и авторизации.

## Стек

Next.js + TypeScript + Supabase (PostgreSQL/Auth). Приложение пока не развёрнуто на хостинге.
