# Kola6a CRM

CRM для управления направлениями бизнеса: домики, пляж, развлечения и водный транспорт, дополнительные услуги, аренда территории и мероприятий.

## Статус

**Этап 1 — каркас проекта.** Интерфейс каталога работает на демонстрационных данных. Подключение реальной БД, авторизация, продажи и финансовый учёт пока не реализованы. Не используйте этот прототип для реального учёта денег.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Технологии

- Next.js (App Router), React, TypeScript
- PostgreSQL / Supabase — целевая база данных
- SQL-миграция в `supabase/migrations/0001_initial.sql`

## Структура

- `src/app/` — интерфейс приложения
- `src/lib/catalog.ts` — типизированный начальный каталог услуг
- `supabase/migrations/` — схема будущей базы данных
- `docs/` — продуктовые правила и этапы разработки

## Безопасность и учёт

В SQL-миграции активирован RLS без открытых политик: доступ клиентов к данным запрещён, пока не реализована проверенная система ролей и серверные операции. Не добавляйте service-role ключ в браузер. Одна продажа и полученные деньги — разные сущности. Перемещение между кассой и сейфом не является выручкой.
